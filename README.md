## 🦉 Sobre mim

Sou o **Coruja**, engenheiro de software focado em **back-end com Java e Spring Boot**, com experiência full stack em **Node.js, TypeScript, React e Angular**. Hoje atuo como **Engenheiro de Software na Mantris**.

Vim da **Engenharia Mecânica** e migrei para tecnologia em 2019. Passei mais de quatro anos na **Trybe**, como desenvolvedor back-end e professor, e ajudei a formar **mais de 1.000 pessoas** em desenvolvimento full stack. Sou pós-graduado em **Arquitetura de Software Distribuído** pela PUC Minas.

## 🚀 O que eu faço

- 🔐 **APIs REST seguras** com Spring Boot e Spring Security, com autenticação, autorização e permissões por perfil de acesso dinâmico
- 🔗 **Integrações com sistemas externos** via REST e SOAP, com webhooks que validam assinatura e controlam idempotência
- ☁️ **AWS** (SES, S3, CloudWatch) para e-mail, armazenamento e observabilidade
- ⚡ **Performance em PostgreSQL**: queries nativas, eliminação de N+1, paginação e filtros dinâmicos
- 🐳 **Docker e CI/CD** com Azure DevOps e Azure Pipelines, com ambientes separados para dev, homologação e produção
